# UI asset source notes

`ui-style-reference.png` is the generated visual reference used to establish
the shared jungle UI language. It is not loaded by the game. Runtime assets are
clean, deterministic pixel-grid redraws generated by
`scripts/generate-ui-assets.py` into `public/assets/ui/`.

## Generation prompt

Use case: stylized-concept. Production reference sheet for a 480x800 pixel-art
jungle platformer UI. Create large and small rounded jungle buttons in normal,
focused, and pressed states; nine-slice wooden/leaf panels; tabs; selection
frames; keyboard keycaps; gamepad A/B/d-pad prompts; toggles; sliders; badges;
score plaques; height markers; pause controls; status icons; and modal frames.
Use crisp modern handheld-game pixel art, chunky stepped corners, three-band
shading, upper-left highlights, transparent gutters, no words, no logos, no
watermark, no gradients, no antialiasing, and the Jungle Jumper master palette.
