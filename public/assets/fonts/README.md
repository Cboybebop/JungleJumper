# Bundled UI font

Jungle Jumper bundles **Silkscreen Regular** and **Silkscreen Bold** for all
in-game UI text. The typeface was designed by Jason Kottke and is distributed
under the SIL Open Font License, Version 1.1.

- Family: Silkscreen
- Version: 1.1 (2001)
- Weights: 400 Regular, 700 Bold
- Upstream project: https://github.com/googlefonts/silkscreen
- Distribution source: https://github.com/google/fonts/tree/main/ofl/silkscreen
- License: `OFL-Silkscreen.txt`
- Upstream metadata: `Silkscreen-METADATA.pb`

The font files are loaded locally by `index.html`; the game does not depend on
platform fonts or a font CDN.
